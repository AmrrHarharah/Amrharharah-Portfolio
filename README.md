# Portofolio Developer (Next.js)
1. Taruh `content.ts` Anda di `data/` (contoh struktur: `data/content.example.ts`).
2. Salin `.env.example` menjadi `.env.local` dan isi nilainya.
3. `npm install` lalu `npm run dev` → http://localhost:3000
Aset (foto, CV, gambar proyek) taruh di `public/`. Admin: /admin. Pintasan: Ctrl/⌘ + K.
